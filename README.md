# bro3_auto_deck_simulator

ブラウザ三国志の所有カードデータを抽出しファイル化します。  
そのファイルをシミュレーター本体に読み込ませる事でデッキを自動で最適化するシミュレートができます。  
このデータを参考にして本サーバーのデッキを構築してみてください。  
引率・単騎・防御(通常防御／南蛮)・北伐に対応しています。  
単騎と北伐がややこしいので参考になるデッキ構成が作れるかもしれません。

## ■やり方  
　まずは武将カードのデータ取得です。  
　「ブラウザ三国志 全カード自動収集シミュレータ連携」スクリプトの登録です。  
　tampermonkey等でスクリプトを登録したら取得したい **「デッキ」** を表示してください。  
　デッキのファイル **「すべて」** を選んで **「大60枚表示」** にした状態で **「天候：晴」** にしておいて  
　右上に追加された **「全ページ自動収集スタート」** ボタンを押せば自動で取得し始めます。  
　完了すると自動でjson形式のファイルをダウンロードします。  
　それが貴方の武将カードの情報です。


　※武将の情報しか入っていませんが取り扱いには注意して下さい。  
  　このスクリプトは取得する時以外はオフにしておくと邪魔にならないです。  
  　晴天候でないと数値が強化された状態で取り込まれるのでバグります。


　次にシミュレーター本体「bro3_simulator.html」をダブルクリックします。   
　chrome等のブラウザで立ち上がるので武将カードの読み込みボタンで   
　先程ダウンロードしたjsonファイルを読み込んでください。


　データ取得時の副将の状態で自動でデッキを組んでくれます。   
　「副将の配置設定」の項目で副将の最適化をする事も出来ます。※ここ逆になってるかも。   
　またデッキコスト30/25や25/30への切り替えや各種天候にも対応しています。
 

　※知力依存等のステータス依存のスキルには対応していません。この辺はブラ３のスキル全データの取り込み＆計算式が必須になるので…   
　　最適副将をセットした状態で武将データを取得すればある程度はシミュできます。
  




## ■カード画像の保存方法  
　サーバー負荷軽減のためにかなり画像をゆっくり読むので画像をダウンロードしないと見ずらいです。
 

　1. シミュレーター画面でJSONを読み込んだあと、右上の「img/保存.bat」ボタンを押すと「3gokushi_img_list.txt」がダウンロードされます。   
　2. ダウンロードされた「3gokushi_img_list.txt」を、フォルダ内の「画像ダウンロード.bat」の上にドラッグ＆ドロップしてください。   
　3. 自動で「img」フォルダが作成され手持ちカードの画像が保存されます（2回目以降は未保存の画像だけを取得します）。
 

　※枚数によって変わりますがそこそこ時間が掛かります。1500枚で10分位。





## ■リストラボタン  
　武将カード右上に禁止マークが見えますがこれを押すとそのカードが選ばれなくなります。   
　どうしてもうまくデッキ構成してくれなかった場合に使って下さい。   
　解除する場合は各タイトルの横にでる解除ボタンをクリックか、図鑑一覧からもう一度クリックすると解除されます。
